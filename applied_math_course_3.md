# Прикладна математика: Курс для учнів 8–10 класів
### «Математика, яка потрібна в житті»

> **Концепція:** Курс усуває прогалину між шкільною математикою та її реальним використанням у природничих науках, економіці, медицині та повсякденному житті. Головний акцент — перетворення текстової задачі на математичну модель та інтерпретація результату.

---

## Структура одного розділу (шаблон)

Кожен розділ курсу побудований за єдиною архітектурою:

### 1. МОТИВАЦІЯ (5–10 хв)
- **Гачок:** реальна ситуація або провокаційне запитання без відповіді
- **Актуальна задача:** конкретний сценарій із реального життя, який учень не може розв'язати без інструментів цього розділу
- **Прев'ю:** що саме вміятимеш після цього розділу

### 2. ТЕОРІЯ (15–25 хв)
- Мінімально необхідний теоретичний матеріал
- Пояснення через приклади, а не через означення
- **Квіз на розуміння** (3–5 запитань): одразу після кожного блоку теорії; миттєвий зворотний зв'язок; адаптивно: хибна відповідь → пояснення + повтор

### 3. ПРАКТИКА З ПІДКАЗКАМИ (20–30 хв)
- 4–6 задач зростаючої складності
- Система підказок: кожне завдання має 2–3 підказки, які відкриваються по одній
- Система рівнів: базовий → стандартний → поглиблений
- Фіксується кількість використаних підказок (вплив на аналітику прогресу)

### 4. ПИСЬМОВЕ ЗАВДАННЯ — ДРУКОВАНА ОСНОВА (офлайн, 20–30 хв)
- Роздруковується учнем або вчителем
- Виконується без електронних засобів
- **Структура бланку:** кожне завдання містить чітко розмічені поля:
  - `[УМОВА]` — надрукована, незмінна
  - `[ХІД РОЗВ'ЯЗАННЯ]` — лінійований прямокутник для роботи
  - `[ВІДПОВІДЬ: ______]` — окремий маленький рядок лише для фінальної відповіді
  - `[ВИСНОВОК / ІНТЕРПРЕТАЦІЯ]` — поле для фрази-пояснення результату
  - опціонально: `[ТАБЛИЦЯ ДЛЯ ЗАПОВНЕННЯ]` або `[ГРАФІК ДЛЯ ПОБУДОВИ]` з готовими осями
- Після виконання: учень фотографує та завантажує → ШІ оцінює (алгоритм описано нижче)

> **Чому структуровані поля?** OCR на полі з відомими координатами і відомим типом вмісту дає суттєво вищу точність, ніж розпізнавання довільного аркуша: система знає, де шукати число і якого формату очікувати. Для числових відповідей (цілі числа, прості дроби) точність висока; для розгорнутих рукописних виразів — нижча, тому такі поля оцінює ШІ. Промпт до ШІ скорочується в 3–5 разів: замість «оціни весь аркуш» — цільова перевірка лише поля `[ВІДПОВІДЬ]` і `[ВИСНОВОК]`.

### 5. ІНТЕРВАЛЬНЕ ПОВТОРЕННЯ (вбудовано в наступні розділи)
- У квізах і письмових завданнях наступних 3–5 розділів з'являються задачі з пройденого матеріалу
- Інтервали: наступний день → через 3 дні → через тиждень → через місяць

## Типи задач

| Тип | Опис | Формат | Приклад |
|-----|------|--------|---------|
| **НМТ-формат** | Тестові задачі з 4–5 варіантами відповіді, одна правильна | Онлайн, офлайн | Розрахунок концентрації розчину |
| **PISA-формат** | Складний контекстний сценарій, кілька пов'язаних запитань, відповідь — числова або коротка | Онлайн, офлайн | Аналіз рахунку за електрику за 6 місяців |
| **Аналіз тексту** | Довгий текст (100–300 слів) з числовими даними; потрібно витягти інформацію та побудувати модель | Офлайн (друкована основа) | Стаття про захворюваність → побудова таблиці → висновок |
| **Аналіз графіка/діаграми** | Готовий графік або діаграма; запитання на читання, порівняння, прогнозування | Онлайн та офлайн | Графік температури → знайти середню, амплітуду, прогноз |
| **Побудова в таблицях** | Задача з даними → побудувати таблицю/графік у Google Sheets / Excel | Онлайн (практика) | Динаміка популяції → стовпчаста діаграма |
| **Відкрите дослідження** | Учень сам збирає дані або отримує датасет, робить висновки | Офлайн + онлайн | Виміряти пульс 10 однокласників → статистика |
| **«Знайди помилку»** | Готове «розв'язання» з помилкою — знайти і виправити | Онлайн | Неправильний розрахунок відсотків у рекламі |
| **Моделювання сценарію** | Вибір між варіантами дій на основі розрахунків | Онлайн | Який кредит вигідніший? |

## Алгоритм оцінювання фото (офлайн-завдань)

**Принцип:** структурований бланк → мінімум токенів, максимум діагностичності.

**Крок 1 — Препроцесинг (локально або дешево):**
- Автокорекція нахилу фото
- Локалізація полів за шаблоном: система знає координати кожного поля на кожному бланку (збережено при генерації PDF)
- OCR застосовується тільки до конкретних полів, а не до всього аркуша

**Крок 2 — Автоматична перевірка (без ШІ):**
- Поле `[ВІДПОВІДЬ]` → порівняти з еталоном числово (± допуск 1–2%)
- Поле `[ТАБЛИЦЯ]` → перевірити заповненість і числові значення
- Якщо відповідь правильна → зарахувати автоматично, токени не витрачаються

**Крок 3 — Цільовий запит до ШІ (тільки коли потрібно):**
Запускається при: неправильній відповіді, нечитабельному полі, або для оцінки поля `[ВИСНОВОК]` (раз на кілька завдань).
```
Задача: [умова]. Еталон: [правильна відповідь].
Хід учня: [текст з поля ХІД РОЗВ'ЯЗАННЯ].
Відповідь учня: [текст з поля ВІДПОВІДЬ].
Висновок учня: [текст з поля ВИСНОВОК].
Визнач тип помилки: обчислювальна / концептуальна / одиниці виміру / неправильна модель / немає помилки.
Оціни висновок: правильний / частково / відсутній.
```

**Крок 4 — Аналітика (зберігається в БД):**
- Правильність відповіді (0/1/частково)
- Тип помилки
- Якість висновку / інтерпретації
- Наявність і логічність ходу розв'язання

## Аналітика прогресу учня (база даних)

Зберігається не лише оцінка, а профіль компетентності:

| Параметр | Що вимірюється |
|----------|---------------|
| Правильність | % правильних відповідей по темі / типу задачі |
| Підказки | Середня кількість підказок; динаміка зменшення |
| Темп | Час на задачу; порівняння з медіаною класу |
| Тип помилок | Обчислювальні / концептуальні / моделювання |
| Глибина занурення | Чи береться поглиблений рівень добровільно |
| Стиль сприйняття | Де більше помилок: текст / графік / формула |
| Інтервальне повторення | Чи утримуються знання через 1/3/7/30 днів |
| Гейміфікація | Очки, серії, досягнення |

## Гейміфікація: найефективніші механіки

### Рекомендовані для цього курсу:

**1. Тижневий і місячний прогрес**
Замість щоденного streak — два горизонти відстеження:
- **Тижневий:** скільки занять пройдено з 7 можливих днів (відображається як «4/7 цього тижня»). Без скидання — показує реальну активність.
- **Місячний:** сумарний прогрес компетентностей за місяць у відсотках. Дозволяє побачити ріст, навіть якщо окремі тижні були слабкими.
Логіка: не карати за пропуск, а показувати тенденцію. Streak-механіки з обнуленням створюють тривогу і контрпродуктивні для навчання.

**2. Прогрес-бар компетентності**
Не «пройшов тему», а «50% майстерності». Відчуття незавершеності мотивує повернутися.

**3. Значки-досягнення (не за оцінки, а за поведінку)**
Приклади: «Детектив» (знайшов помилку в задачі), «Без підказок» (3 задачі поспіль), «Швидкий розум» (задача за < 2 хв), «Наполегливий» (повторив тему після помилки).

**4. Класовий рейтинг (опціональний, анонімний)**
Важливо: не рейтинг «хто кращий», а «хто найбільше прогресував за тиждень».

**5. Математичні міні-ігри (вбудовані між модулями)**

| Гра | Математичний зміст | Механіка |
|-----|-------------------|----------|
| **«Зупини армію»** | Лінійне / показникове зростання | Армія наступає щохода; потрібно розрахувати, скільки «заклинань» знищать її до підходу |
| **«Мости»** | Графи, найкоротший шлях | Вибір маршруту з обмеженнями |
| **«Паркування»** | Просторова логіка + нерівності | Розмістити машини за умовами |
| **«Ринок»** | Відсотки, знижки, ПДВ | Купити набір товарів із бюджетом |
| **«Епідемія»** | Показниковий ріст, відсотки | Зупинити поширення вірусу вакцинацією |
| **«Фондова біржа»** | Графіки, тренди, % зміни | Купити/продати акції за 5 ходів |
| **«Будівельник»** | Площі, пропорції, кошторис | Побудувати будинок у бюджеті |

**6. Наратив і прогресія персонажа**
Необов'язково, але ефективно для 8-го класу: учень — «аналітик» або «дослідник», кожен завершений розділ відкриває нову локацію або інструмент.

## Програма курсу

### МОДУЛЬ 0. Вступ: Математика як мова реальності
*(2 заняття)*

**Після цього модуля учень зможе:**
- Відрізняти точний розрахунок, оцінку і прогноз
- Самостійно аналізувати текстову задачу за алгоритмом: виділення даних → вибір інструменту → перевірка смислу відповіді
- Визначати задачі з надлишковими або недостатніми даними

- Що означає «побудувати математичну модель»
- Алгоритм роботи з текстовою задачею: читання → виділення даних → вибір інструменту → розв'язання → перевірка смислу відповіді
- Типи математичних тверджень: точний розрахунок, оцінка, прогноз
- Практика: «сміттєві» задачі з надлишковими або недостатніми даними

---

### МОДУЛЬ 1. Читання даних: графіки, таблиці, діаграми
*(3–4 заняття)*

**Після цього модуля учень зможе:**
- Обрати правильний тип діаграми для конкретного набору даних
- Виявити маніпуляцію з графіком (зрізана вісь, неправильна шкала)
- Побудувати діаграму в Google Sheets за табличними даними
- Пояснити різницю між кореляцією і причинністю на конкретному прикладі

**Розміщення:** навмисно перший — після вступу. Навички читання і побудови візуалізацій використовуються в усіх наступних модулях як спільна мова.

**Контексти:** усі предмети; особливо — географія, екологія, соціологія, економіка

**Теми:**
- Типи діаграм і коли який обирати (стовпчаста, кругова, лінійна, точкова)
- Читання таблиць: як витягнути потрібну інформацію
- Побудова діаграм у Google Sheets: крок за кроком
- Хибні діаграми: зрізана вісь, неправильна шкала, вибіркові дані
- Кореляція ≠ причинність (класичні приклади)
- Основи читання наукових таблиць і графіків

**Актуальна задача-мотивація:** Два графіки показують «зростання злочинності» в одному місті. Один — тривожний, інший — спокійний. Однакові дані. Чому?

**Зв'язок із наступними модулями:** у кожному наступному розділі учні будують або читають графіки, використовуючи інструменти цього модуля.

---

### МОДУЛЬ 2. Відсотки і частки
*(4–5 занять)*

**Після цього модуля учень зможе:**
- Переходити між формами запису: %, дріб, десяткове число
- Розраховувати відсотковий приріст і спад, складні відсотки
- Розпізнавати типові маніпуляції з відсотками в медіа та рекламі
- Розв'язати задачу типу «знижка 30%, потім ще 20%» без помилок

**Контексти:** біологія (вміст речовин), хімія (концентрація розчинів), медицина (ефективність вакцини, ризики), фінансова грамотність (знижки, ПДВ, інфляція), соціологія (результати опитувань), екологія (частка забруднення)

**Теми:**
- Відсоток як частка від цілого; переходи між формами запису (%, дріб, десяткове)
- Знайти відсоток від числа; знайти число за його відсотком
- Відсотковий приріст і спад; «відсоток від відсотка»
- Складні відсотки (банківські вклади, радіоактивний розпад)
- Помилки у відсоткових розрахунках (типові медіа-маніпуляції)

**Актуальна задача-мотивація:** Реклама говорить «знижка 30%, потім ще 20%». Це 50%? Розрахуй.

**Ключова складність:** переплутати «30% від початкової ціни» і «30% від ціни після першої знижки»

**Гра-вставка:** «Ринок» — купити кошик товарів із бюджетом, врахувавши знижки та ПДВ

---

### МОДУЛЬ 3. Дроби і пропорції
*(3–4 заняття)*

**Після цього модуля учень зможе:**
- Виконувати дії з дробами і спрощувати вирази
- Складати і розв'язувати пропорції для задач масштабу і дозування
- Розраховувати дозу ліків за масою тіла і концентрацією розчину
- Відрізняти пряму і обернену пропорційні залежності та застосовувати відповідну формулу

**Контексти:** хімія (мольні частки, рецептури), кулінарія/харчування (побутова економіка), картографія (масштаб), фізика (механічне перевантаження), медицина (дозування ліків)

**Теми:**
- Звичайні та мішані дроби: дії, спрощення
- Пропорція та метод пропорції
- Масштаб і коефіцієнт подібності
- Пряма і обернена пропорційна залежність
- Дозування: як розраховується доза ліків на кг маси тіла

**Актуальна задача-мотивація:** Лікар призначає 5 мг/кг. Дитина важить 34 кг. Сироп містить 125 мг/5 мл. Скільки мл давати?

**Гра-вставка:** «Будівельник» — розрахувати кількість матеріалів за кресленням у масштабі

---

### МОДУЛЬ 4. Стандартний вигляд числа і одиниці виміру
*(2–3 заняття)*

**Після цього модуля учень зможе:**
- Записувати і порівнювати числа у стандартному вигляді (науковій нотації)
- Переводити між одиницями SI і виявляти типову помилку «км² ≠ тисяча м²»
- Оцінювати порядок величини відповіді (Fermi-підхід)
- Впевнено працювати з дуже великими і дуже малими числами у контексті фізики та хімії

**Контексти:** фізика (астрономічні та атомні масштаби), хімія (число Авогадро, молярна маса), біологія (розміри клітин), географія (відстані)

**Теми:**
- Степені числа 10; стандартний вигляд (наукова нотація)
- Переведення між одиницями (SI-система)
- Порівняння чисел у стандартному вигляді
- Типові помилки: «км² ≠ тисяча м²»
- Оцінка порядку величини (fermi-задачі)

**Актуальна задача-мотивація:** Скільки клітин у тілі людини? Скільки разів вони б вкрили поверхню землі?

**Гра-вставка:** «Зупини армію» — армія множиться кожен хід; розрахувати, коли вона перевищить порогове число

---

### МОДУЛЬ 5. Лінійні рівняння і нерівності
*(4–5 занять)*

**Після цього модуля учень зможе:**
- Скласти рівняння за умовою текстової задачі (схема «нехай x = …»)
- Розв'язати систему двох лінійних рівнянь методом підстановки і графічно
- Зобразити лінійну нерівність на числовій прямій
- Виразити одну змінну з формули через інші (перетворення)

**Контексти:** фізика (рівномірний рух, закон Ома), економіка (беззбитковість, точка рівноваги), медицина (розрахунок дози за масою і часом), соціологія (планування бюджету)

**Теми:**
- Складання рівняння за умовою задачі (схема: «нехай x = …»)
- Лінійне рівняння з однією змінною
- Система двох лінійних рівнянь (метод підстановки і графічний)
- Лінійна нерівність та її графік
- Формула як рівняння: виразити одну змінну через інші

**Актуальна задача-мотивація:** Два кур'єри виїхали назустріч одне одному. Коли і де зустрінуться? (класика — але через реальний контекст: доставка дронами)

**Ключова складність:** побудова рівняння з тексту; «підводні камені» зі знаками

### МОДУЛЬ 6. Функції та графіки
*(5–6 занять)*

**Після цього модуля учень зможе:**
- Читати і описувати поведінку функції за її графіком (де зростає, де спадає, максимум, мінімум)
- Відрізняти лінійну, квадратичну і показникову залежності за формою графіка
- Пояснити поняття «період» і «амплітуда» на прикладі природних процесів
- Побудувати графік за таблицею значень у Google Sheets і зробити прогноз

**Контексти:** фізика (графіки руху, залежність сили від відстані, коливання), біологія (ріст популяцій, добові ритми), медицина (фармакокінетика — концентрація ліків у крові), кліматологія (температурні ряди), акустика (звукові хвилі)

**Теми:**
- Поняття функції; способи задання (таблиця, графік, формула)
- Лінійна функція: нахил і перетин з осями
- Квадратична функція (базово: парабола, вершина, вигляд)
- Показникова функція (ріст і спад): подвоєння, напівперіод
- **Періодичні функції** — без складних формул, на рівні розуміння:
  - Що таке період і амплітуда
  - Приклади з природи: добовий ритм температури, серцевий ритм, сезонні коливання, звукові хвилі
  - Читання та інтерпретація синусоїдоподібних графіків
  - Прогнозування за циклічними даними
- Читання графіків: де зростає, де спадає, максимум, мінімум, точки перетину
- Побудова графіків у таблицях (Google Sheets / Excel)

**Актуальна задача-мотивація:** Графік концентрації парацетамолу в крові. Коли приймати наступну дозу? Чи не перевищить вона безпечний рівень?

**Гра-вставка:** «Фондова біржа» — читати графіки акцій, приймати рішення про купівлю/продаж

### МОДУЛЬ 7. Математична статистика
*(4–5 занять)*

**Після цього модуля учень зможе:**
- Обчислити середнє, медіану і моду та пояснити, коли кожна з них інформативніша
- Побудувати гістограму і box plot за реальними даними
- Інтерпретувати стандартне відхилення інтуїтивно (без складних формул)
- Виявити маніпуляцію статистикою у ЗМІ або рекламі

**Контексти:** біологія (варіабельність ознак), медицина (клінічні дослідження, норми аналізів), соціологія (опитування і їхні похибки), екологія (моніторинг забруднення), спорт (аналіз результатів)

**Теми:**
- Генеральна сукупність і вибірка
- Середнє арифметичне, медіана, мода — коли що використовувати
- Розмах і стандартне відхилення (інтуїтивно, без складних формул)
- Гістограма і діаграма «ящик з вусами» (box plot)
- Нормальний розподіл: 68–95–99,7% правило
- Маніпуляції зі статистикою: як обманюють графіками

**Актуальна задача-мотивація:** Середня зарплата в Україні — X гривень. Чому більшість людей отримують менше? (Медіана vs середнє)

**Відкрите дослідження:** виміряти зріст/пульс/час реакції у класі → побудувати гістограму → порівняти з нормою

### МОДУЛЬ 8. Імовірність
*(3–4 заняття)*

**Після цього модуля учень зможе:**
- Обчислити класичну імовірність події і її доповнення
- Визначити, чи є події незалежними, та розрахувати імовірність їхнього поєднання
- Обчислити математичне сподівання і застосувати його для оцінки «вигідності» гри або лотереї
- Читати і критично інтерпретувати імовірнісні твердження в медіа (прогноз погоди, медичні ризики)

**Контексти:** медицина (ризики, чутливість тестів), генетика (закони Менделя), страхування (фінансова грамотність), метеорологія (прогноз погоди), ігри (критичний аналіз)

**Теми:**
- Класична імовірність: формула, перерахунок варіантів
- Доповнення події; «хоча б один»
- Незалежні та залежні події; множення імовірностей
- Очікуване значення (математичне сподівання)
- Чому лотерея — поганий фінансовий план
- Як читати медичні ризики: «ризик підвищується на 30%» — від якої бази?

**Актуальна задача-мотивація:** Монету підкинули 5 разів і щоразу випадав орел. Яка імовірність орла на 6-му підкиданні? (Розвінчання «закону великих чисел» у побутовому розумінні)

**Гра-вставка:** «Генетика» — передбачити розподіл ознак у нащадків за решіткою Пеннета

### МОДУЛЬ 9а. Читання і перетворення формул
*(2–3 заняття)*

**Після цього модуля учень зможе:**
- Читати формулу: пояснити фізичний зміст кожного символу та залежності
- Виразити будь-яку змінну з формули (алгебраїчні перетворення без помилок зі знаками)
- Перевірити коректність формули через розмірний аналіз одиниць
- Застосувати навичку до формул з фізики, хімії і медицини без попередньої підготовки

**Контексти:** фізика (кінематика, динаміка, термодинаміка), хімія (газові закони, розчини), медицина (фізіологічні індекси — ІМТ, ШКФ), фінансова грамотність (кредит, вклад)

**Теми:**
- Читання формули: що означає кожен символ, від чого залежить результат
- Перетворення формули — виразити потрібну змінну (алгебраїчні маніпуляції)
- Підстановка значень і перевірка одиниць виміру (розмірний аналіз)
- Типові помилки при перетворенні: знаки, ділення на змінну, квадратний корінь

**Актуальна задача-мотивація:** Формула гальмівного шляху: s = v²/2a. Яка швидкість була, якщо слід на асфальті — 40 м?

> **Примітка:** Навичка перетворення формул навмисно вводиться раніше модуля 9б і паралельно підсилюється у фізичних та хімічних контекстах модулів 3–8 через спеціальні задачі «виведи з формули».

### МОДУЛЬ 9б. Побудова математичних моделей
*(2–3 заняття)*

**Після цього модуля учень зможе:**
- Побудувати математичну модель за словесним описом задачі (таблиця → формула → графік)
- Застосувати ітераційний підхід у таблиці, коли аналітичної формули немає
- Оцінити обмеження моделі: за яких умов вона перестає описувати реальність
- Порівняти дві моделі за точністю та визначити, яка підходить для конкретної задачі

**Контексти:** фізика (всі розділи), хімія (газові закони), біологія (логістичний ріст), фінансова грамотність (складні відсотки, кредит), екологія

**Теми:**
- Від задачі до моделі: алгоритм побудови
- Складання формули за закономірністю (таблиця → формула → графік)
- Чисельні методи: коли аналітичної формули немає — ітерації в таблиці
- Обмеження моделі: модель ≠ реальність; коли модель «зламується»
- Порівняння моделей: яка точніша і за яких умов

**Актуальна задача-мотивація:** Ти взяв кредит 50 000 грн під 24% річних на 2 роки. Скільки реально заплатиш? Збудуй модель у таблиці і порівняй з рекламою банку.

### МОДУЛЬ 10. Інтеграційний проєкт: «Дослідник»
*(4–5 занять + самостійна робота)*

#### Концепція

Учень отримує **набір реальних даних** із обраної галузі — і далі діє самостійно: сам вирішує, що саме аналізувати, яку модель будувати, який висновок формулювати. Учитель або платформа **не ставить конкретного запитання** — лише надає дані і контекст. Це принципова відмінність від звичайної задачі.

Вибір відбувається на **двох рівнях:**

**Рівень 1 — Галузь** (учень обирає одну):

| # | Галузь | Що отримує учень |
|---|--------|-----------------|
| А | 🏥 Охорона здоров'я | Дані захворюваності, результати аналізів популяції, статистика щеплень |
| Б | 🌍 Екологія та клімат | Температурні ряди, рівень CO₂, якість повітря або води в містах України |
| В | 💰 Особисті фінанси | Модельний сімейний бюджет за рік, тарифи, ціни, інфляція |
| Г | 🧬 Біологія і природа | Динаміка популяцій тварин, фенологічні спостереження, врожайність |
| Д | 🏙️ Місто і суспільство | Демографічні дані, транспортне навантаження, результати опитувань |
| Е | ⚽ Спорт і фізична активність | Статистика змагань, фізіологічні показники, тренувальні дані |
| Є | 🔬 Фізика і хімія навколо нас | Вимірювання температури, тиску, pH, даних про матеріали |
| Ж | 📱 Технології та медіа | Статистика використання застосунків, ціни на техніку, енергоспоживання |

**Рівень 2 — Власне дослідницьке запитання** (учень формулює сам)

Після знайомства з даними учень формулює **одне конкретне запитання**, на яке відповідатиме. Наприклад, якщо обрана галузь Б (екологія):
- «Чи є зв'язок між температурою і якістю повітря в Києві?»
- «Як змінювалась середня температура за останні 20 років — і що буде через 10?»
- «В якому місяці найвища концентрація CO₂ і чому?»

> Платформа показує **3–4 приклади можливих запитань** до кожного датасету — не як обов'язкові варіанти, а як ілюстрацію того, як можна думати. Учень може взяти одне з них або придумати своє.

---

#### Етапи роботи

**Заняття 1 — Занурення в дані (онлайн або офлайн)**
- Учень отримує датасет (таблиця, 30–100 рядків) і короткий опис контексту
- Завдання: уважно переглянути дані, відзначити, що здається цікавим, незвичним, несподіваним
- Виходить з заняття з **формулюванням свого запитання** (1–2 речення)
- Вчитель або платформа коротко схвалює або пропонує уточнити формулювання

**Заняття 2 — Вибір інструментів і план (онлайн)**
- Учень обирає: які математичні інструменти з курсу знадобляться (мінімум два)
- Складає план аналізу: які розрахунки, яку візуалізацію, який формат висновку
- Платформа показує **чек-лист**: «Чи є у твоєму плані графік? Формула або модель? Числовий висновок? Інтерпретація?»

**Заняття 3–4 — Аналіз і розрахунки (самостійно, онлайн + офлайн)**
- Учень виконує розрахунки, будує графіки (Google Sheets або від руки)
- Офлайн-компонент: частина роботи — на друкованому бланку з полями для проміжних розрахунків, таблиці та висновку
- Платформа надає **підказки на запит** (не автоматично): загальні — про інструмент, не про конкретний датасет учня

**Заняття 5 — Презентація і рефлексія**
- Учень готує коротку презентацію: **1 аркуш або 2–3 слайди**
- Обов'язкові елементи: запитання → дані → модель/розрахунок → графік → висновок → обмеження моделі
- Формат: усна презентація перед класом / запис відео / письмовий звіт — учень обирає
- Рефлексія: що вийшло добре, що було найважче, що б зробив інакше

#### Критерії оцінювання

| Критерій | Що оцінюється | Вага |
|----------|--------------|------|
| Запитання | Чи конкретне, реалістичне, цікаве? | 10% |
| Робота з даними | Чи правильно прочитані та відібрані дані? | 20% |
| Математична модель | Чи використано ≥2 інструменти курсу? Чи коректно? | 30% |
| Візуалізація | Чи підходить тип графіка? Чи підписані осі? | 15% |
| Висновок | Чи відповідає на поставлене запитання? Чи є інтерпретація? | 20% |
| Обмеження | Чи зазначено, де модель може помилятися? | 5% |

> **Немає єдиної правильної відповіді.** Оцінюється якість мислення і коректність інструментів, а не збіг із еталоном.

#### Приклади реальних датасетів для кожної галузі

- **А (здоров'я):** захворюваність на грип по областях України за 5 років; відсоток вакцинованих vs захворілих
- **Б (екологія):** щомісячна температура в Києві за 1990–2024; індекс якості повітря AQI по містах
- **В (фінанси):** модельний бюджет сім'ї з 4 осіб за 12 місяців з різними статтями витрат
- **Г (біологія):** чисельність бусла в Україні за 30 років; динаміка лісового покриву
- **Д (місто):** завантаженість метро Києва по станціях і годинах; динаміка населення міст
- **Е (спорт):** результати учнів школи на нормативах за 3 роки; статистика НБА-команди за сезон
- **Є (фізика/хімія):** вимірювання pH річок різних регіонів; дані про теплопровідність матеріалів
- **Ж (технології):** ціни на смартфони за 5 років з урахуванням інфляції; енергоспоживання побутових приладів

## Роль вчителя

### Принцип: мінімальне залучення, максимальна видимість

Курс розроблений як **максимально автоматизований**: система сама перевіряє завдання, дає підказки, відстежує прогрес і пропонує повторення. Вчитель не є основним «двигуном» навчання — але є ключовим спостерігачем і коректором.

### Що робить система автоматично (без вчителя)
- Перевірка квізів і числових відповідей
- Видача підказок у практичних завданнях
- Оцінювання фото офлайн-завдань (OCR + ШІ за потреби)
- Інтервальне повторення (алгоритм SM-2)
- Генерація тижневого/місячного звіту по учню
- Сповіщення учню про нові заняття і повторення

### Що робить вчитель

**Щотижня (~15–20 хв):**
- Переглядає дашборд класу: загальний прогрес, «червоні прапорці» (учні з >30% помилок у темі)
- Реагує на автоматичні сповіщення: «Учень N застряг на темі X вже 3-й тиждень»

**За потреби (не регулярно):**
- Редагує або деактивує конкретні задачі (наприклад, якщо умова незрозуміла або застаріла)
- Додає власні задачі до будь-якого модуля через редактор завдань
- Коментує роботи учнів вручну (для завдань, де ШІ не впевнений)
- Налаштовує темп класу: «пропустити» модуль або «розтягнути» його на більше тижнів

**На початку курсу (одноразово):**
- Реєструє клас, налаштовує групи
- Ознайомлюється з програмою і за потреби коригує перелік модулів

### Дашборд вчителя

| Функція | Опис |
|---------|------|
| Огляд класу | Прогрес кожного учня по модулях (теплова карта компетентностей) |
| Червоні прапорці | Автоматичний список учнів, які відстають або мають системні помилки |
| Типи помилок класу | Агрегована аналітика: де весь клас помиляється найчастіше |
| Редактор завдань | Перегляд, редагування, деактивація або додавання задач по модулях |
| Ручне оцінювання | Черга завдань, які система не змогла оцінити автоматично |
| Звіти | Тижневий/місячний PDF-звіт по класу або окремому учню |

### Що вчитель НЕ має робити вручну
- Перевіряти звичайні завдання з числовою відповіддю
- Нагадувати учням про заняття (це робить система)
- Вести журнал помилок (він формується автоматично)

## Технічна архітектура (коротко)

### База даних учня
Кожен учень має профіль із:
- Вектором компетентностей (по кожній темі: 0–100%)
- Журналом помилок (тип, тема, дата)
- Картою повторень (алгоритм SM-2 або спрощений FSRS)
- Метриками поведінки (підказки, темп, вибір складності)

### Адаптивність
- Якщо учень бере поглиблені задачі → пропонувати більше
- Якщо багато помилок «на моделювання» → більше задач «текст → формула»
- Якщо підказки не зменшуються → запропонувати повтор теорії

### Офлайн-оцінювання (економія токенів)
1. Локальне OCR (Tesseract або Google ML Kit) → розпізнати числа та формули
2. Порівняти відповідь із еталоном (числова перевірка ± допуск)
3. ШІ залучається тільки при: нечитабельному фото, нестандартній формі відповіді, або для оцінки ходу розв'язання (раз на кілька завдань)

---

### Наскрізна нитка: перетворення формул
Навичка виведення і перетворення формул не обмежується модулем 9а. Починаючи з модуля 4, у кожному розділі є мінімум одна задача типу «виведи з формули потрібну величину» у контексті відповідного предмету (фізика, хімія, медицина). Це забезпечує накопичення навички через повторення в природному контексті, а не ізольоване тренування.
